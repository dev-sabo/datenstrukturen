Der Stack (Stapelspeicher)

Prinzip: LIFO (Last-In, First-Out).

Ein Stack funktioniert wie ein Stapel Teller. Das Element, das als letztes hinzugefügt wurde (Push), ist das erste, das wieder heruntergenommen wird (Pop). Man hat immer nur Zugriff auf das oberste Element.

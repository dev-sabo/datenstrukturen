Die Hash Table (Hashtabelle)

Prinzip: Schlüssel-Wert-Paare (Key-Value) und Hashing.

Eine Hashtabelle speichert Daten, indem sie einen Schlüssel (Key) mithilfe einer Hashfunktion in einen Index umwandelt. Dieser Index gibt an, wo der zugehörige Wert (Value) im Speicher liegt. Das ermöglicht extrem schnelles Speichern und Suchen.
